# CloseLens · 收盘透镜

**一次可靠取数 → 完整股票研究 → 模型综合 → 验证 → 可核验交付。**

A compact agent skill for source-backed US-equity research and verified closing reports.

CloseLens 把行情、公司/ETF研究、模型比较和交付整理成一条简洁流程。适合单股研究、主题比较或完整自选股收盘报告；配置52项名单时逐项覆盖，不用少数重点替代其余项目。

## 为什么使用它

- 一份事实包共享给不同方法，减少重复取数与无效模型调用。
- 公司和ETF使用不同框架；短期与1—4周情景分开。
- 保留来源、时点、调整口径、风险与缺口，不编造独立模型共识。
- 中断后复用可核验阶段；发送结果不明时先查，避免重复邮件。
- 完整正文与真实SENT回执一致才算交付完成。

## 安装与使用

将本仓库的 `closelens` 文件夹复制到 Codex 的 `~/.codex/skills/`，或安装到支持SKILL.md的代理环境。

示例：

> 使用 $closelens 研究我的已确认自选股，区分下一交易时段与未来1—4周，给出证据、条件和风险。

> 使用 $closelens 在实际收盘后完成全部52项研究和模型综合；按我已授权的收件人发送，并核对完整SENT回执。

普通研究不需要邮件工具。实际取数、模型调用、定时执行和邮件交付需要使用者环境提供对应工具与授权；本仓库不是独立运行的交易机器人或定时服务。不会替你购买API、提供账户权限或保证投资收益。

## 内容

- `closelens/SKILL.md`：五阶段主流程和报告标准。
- `closelens/references/delivery.md`：时点、续接、防重和全文回执规范。
- `closelens/agents/openai.yaml`：技能显示信息。

公开包不包含私人自选股名单、邮箱、密钥、本机路径、真实报告或邮件回执。个人本地部署中的脚本、服务和自动化并未随本包公开。
